# DS203 oscilloscope (HW 2.6x / 2.7x)

The DS203 of e-Design / Miniware, hardware 2.6x and 2.7x, has an
iCE65L04F-TVQ100C next to an STM32F103VC. (Hardware 2.81 has an iCE40 8k
instead, which the unpatched icestorm supports.) Its FPGA is configured
from the STM32 at power up: the image lives in the STM32 flash at
0x0802C000 and SYS (the vendor's system firmware) loads it into the FPGA.
A bad image cannot damage anything; the original is flashed back the same
way.

## Pins

`examples/ds203_pins/ds203_l04_vq100.pcf` lists all 45 FPGA pins whose pad
is known, with the signal names of the schematic:

| Signal | Pins | Direction | Function |
| --- | --- | --- | --- |
| MCI | 15 | in | sampling clock from the STM32 (MCO / timer), up to 72 MHz; global buffer pin |
| AQ[7:0], CKA | 78–87, 81 | in, out | ADC channel A data, its clock |
| BQ[7:0], CKB | 90–99, 100 | in, out | ADC channel B data, its clock |
| CTr, DTr | 24, 25 | in | digital inputs CH_C, CH_D |
| DB[15:0] | 20–59 | in/out | 16 bit data bus of the STM32 FSMC (bank at 0x64000000) |
| NE1, nRD | 27, 29 | in | FSMC chip select and read strobe |
| H_L, ClrR | 64, 65 | in | GPIO PC5 / PC4 of the STM32 (word select, called C_D in the FPGA sources) |
| ClrW | 62 | in | GPIO PB1 |
| SCK, SDA | 68, 66 | in | GPIO PA6 / PA7: serial register writes of SYS (`Set_Param`) |
| nPD | 2 | out | ADC power down |

The schematic swaps the labels BQ0 and BQ1; the pin file follows the vendor
image and the Pins.pcf of e-Design (BQ[0] on pin 90).

## First light: examples/ds203_blinky

```sh
flow/ice65-build -t ds203_blinky -p examples/ds203_blinky/ds203_blinky.pcf \
    -o build/blinky examples/ds203_blinky/ds203_blinky.v
```

On the device: nPD (pin 2) toggles at about 1 Hz, CKA 1.125 MHz, CKB
562.5 kHz; the bus answers 0xA55A (H_L = 1) or the number of read strobes
(H_L = 0). The oscilloscope does not work with it; it shows that the FPGA
is configured and runs. Not yet tried on hardware (the image below was).

## Flashing

1. Start the DS203 in DFU mode (USB disk of the boot loader, as for a SYS or
   APP update).
2. Copy `CFG_FPGA.ADR`: a text file with `0x0802C000` and CR LF.
3. Copy the image, e.g. `V264FPGA.BIN` (68088 bytes). The disk reconnects;
   the name ending changes to `.RDY` when it is written.
4. Restart the device. SYS reports the FPGA version (bits 15..6 of the
   status word: 2.61 for the stock image).

To go back: the same with the stock `V261FPGA.BIN`
([gabonator/LA104](https://github.com/gabonator/LA104), `tools/fpga/ds203_8mb_hwV272-V261FPGA`).

## A complete design: FPGA 2.64

The oscilloscope FPGA of e-Design with edge counters and quadrature
decoders, built with this flow and running on HW 2.7:
[Kuzma30/LA104](https://github.com/Kuzma30/LA104), `system/fpga_ds203`
(sources, `ice65/build_l04.sh`, three-level regression), image in
`tools/fpga/ds203_hw26x_V264FPGA`, tester application
`system/apps_ds213/64_fpgatest`.

Two points from that port that apply to any DS203 design:

- Memory deeper than 256 words: `lib/ram4096_l04.v`.
- Take MCI from its pad onto global network 1 with `SB_GB_IO`
  (`PIN_TYPE(6'b000001)`): it is the confirmed pad-driven buffer, and keeps
  the three fabric-driven buffers for other clocks.
